# Pidgeon for JavaScript

Email inboxes for AI agents. Generated from Pidgeon's private repository on every release; change nothing here.

| Package | npm |
| --- | --- |
| [`@pidgeon-ai/sdk`](packages/sdk) | The SDK: email inboxes for AI agents, pods and Sign in with Pidgeon |
| [`@pidgeon-ai/cli`](packages/cli) | `pidgeon`, the command line |
| [`@pidgeon-ai/mcp`](packages/mcp) | `pidgeon-mcp`, the MCP server |
| [`@pidgeon-ai/ai-sdk`](packages/ai-sdk) | The MCP server's tools for the Vercel AI SDK |
| [`@pidgeon-ai/n8n-nodes-pidgeon`](packages/n8n) | The n8n community node: inboxes in workflows |

Each version is published from a tag here by `.github/workflows/publish.yml`,
with npm provenance. Issues: support@pidgeon.ai.
